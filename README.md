# 列車なう プライバシーポリシー

運営者：ggs-ud  
制定日：2026年9月28日

> **公開前の確認事項：** お問い合わせ先のメールアドレスが未設定です。この欄を確定してから公開してください。

本ポリシーは、ggs-ud が提供する Android アプリ「列車なう」に適用されます。本アプリで扱う情報と、その利用方法を説明します。

## 1. 取得・利用する情報

- **位置情報：** 利用者が許可した場合、現在地、測位精度、移動速度などを取得します。近くの路線・駅の候補表示、駅への接近や通過の判定、案内・通知の更新に使用します。案内を開始すると、画面を閉じた後も通知を表示するフォアグラウンドサービスで測位を続ける場合があります。位置情報の権限は Android の設定から変更できます。
- **アプリ内の設定・利用状態：** 選択した路線、列車種別、方向、表示設定、権限を要求済みかどうかなどを端末内に保存し、案内の再開や表示に使用します。
- **端末内の動作ログ：** 判定した駅名、駅までの距離、速度、測位精度、案内状態の変化などを、動作確認のため端末内のアプリ専用領域に記録します。ログは日付ごとに保存され、別の日に次のログを書き込む際に過去の日付のログを削除します。
- **利用状況・端末識別子：** Google Analytics for Firebase が、アプリの起動・画面表示・利用セッション、アプリインスタンス ID、端末やアプリの情報、IP アドレスから推定されるおおまかな地域を自動的に収集します。端末や設定により広告 ID も収集されます。アプリの利用状況の把握と改善に使用します。
- **不具合・診断情報：** Firebase Crashlytics が、クラッシュや例外の情報、端末・OS・アプリの情報、インストール識別子などを収集します。また、本アプリは不正な状態遷移などの診断のため、選択した路線や列車種別、判定した駅名、駅までの距離、速度、測位精度、状態変化を含むログを Crashlytics に送信する場合があります。駅名などの情報から、おおまかな移動状況が推測される可能性があります。

本アプリは、取得した緯度・経度を運営者独自のサーバーに保存する機能を実装していません。ただし、上記の診断情報には位置に関連する判定結果が含まれます。また、測位には Android および Google Play 開発者サービスの機能を使用します。

## 2. 外部サービスと情報の送信

本アプリは、Google LLC が提供する Google Play 開発者サービス（測位）、Google Analytics for Firebase（利用状況の分析）、Firebase Crashlytics（不具合の調査）を使用します。これらのサービスに送信された情報は、各サービスの規約とプライバシーに関する説明に従って処理されます。

- [Google プライバシーポリシー](https://policies.google.com/privacy?hl=ja)
- [Firebase のプライバシーとセキュリティ](https://firebase.google.com/support/privacy?hl=ja)

法令に基づく場合を除き、運営者が利用者の情報を販売することはありません。

## 3. 端末内の保存とバックアップ

設定と動作ログは、アプリの専用領域に保存します。Android のバックアップが有効な端末では、端末内のアプリデータが Google のバックアップまたは端末間のデータ移行の対象となる場合があります。アプリをアンインストールすると端末内のアプリデータは削除されますが、バックアップや外部サービスに保存済みの情報には、それぞれの保存・削除の仕組みが適用されます。

## 4. 保存期間と削除

端末内の設定は、利用者がアプリのデータを消去するか、アプリをアンインストールするまで保存されます。端末内の動作ログは、上記の日付更新時の削除、アプリデータの消去、またはアンインストールによって削除されます。Firebase に送信された情報の保存期間は各サービスの設定と方針によります。Crashlytics のクラッシュ情報と関連識別子は、Google の説明では通常 90 日後に削除処理が始まります。削除について相談したい場合は、下記の問い合わせ先にご連絡ください。

## 5. 利用者による選択

位置情報と通知の権限は、Android の設定から許可・拒否または変更できます。位置情報を許可しない場合、近くの駅の案内など一部の機能を利用できません。案内中の測位は、アプリの案内を停止すると終了します。端末内の情報は、Android のアプリ設定からデータを消去するか、アプリをアンインストールすることで削除できます。

## 6. 本ポリシーの変更

アプリの機能や利用するサービスを変更した場合、本ポリシーを更新し、変更後の内容をこのページに掲載します。必要に応じてアプリ内でもお知らせします。
